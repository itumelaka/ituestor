# ITU eSTOR

ITU eSTOR ialah platform pengurusan stor untuk Institut Teknologi Unggas, dibangunkan sebagai dashboard 3D Clay dan dihoskan melalui GitHub Pages.

Sistem ini menggunakan Cloudflare Worker sebagai backend, Supabase Google Auth untuk log masuk melalui Akaun Google, serta Google Sheets Native dalam Google Drive sebagai storan data. Google Apps Script tidak digunakan.
